# 🏠 House Price Analysis & Prediction

A machine learning project that analyzes housing data, performs data preprocessing, explores feature relationships, and compares multiple regression models to predict house prices.

## Objectives

- Analyze housing datasets
- Perform data cleaning and preprocessing
- Explore feature correlations
- Train and compare regression models
- Evaluate model performance

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn

## Machine Learning Models

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Support Vector Regression (SVR)

## Project Workflow

1. Import Dataset
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Feature Engineering
5. Data Visualization
6. Train/Test Split
7. Feature Scaling
8. Model Training
9. Model Evaluation
